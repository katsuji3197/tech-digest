summary: Apache HTTP Server の mod_http2 に、認証なしで遠隔からコードを実行されうる重大な脆弱性（CVE-2026-119618）。影響は 2.4.55〜2.4.70 で HTTP/2 を有効にしているサーバー。修正版 2.4.71 は11月11日公開、すぐ更新できなければ `Protocols http/1.1` で HTTP/2 を止めるのが暫定策です。
---

自社の Web サーバーやリバースプロキシ、ステージング環境で Apache を HTTP/2 付きで動かしていないか、今日のうちに確かめてください。影響する条件、ディストリごとの修正状況、確認と対処の手順をまとめました。
