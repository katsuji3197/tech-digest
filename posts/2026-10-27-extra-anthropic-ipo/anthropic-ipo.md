Claude を開発する Anthropic が、米国時間10月26日（月）、上場のための登録届出書 **S-1** を米証券取引委員会（SEC）に公開しました。**Nasdaq Global Select Market にティッカー「ANT」で上場する**計画です。TechCrunch の記事は太平洋時間26日7時35分（日本時間26日23時35分）に出ており、日本の X でも「アンソロピック」「目論見書」がトレンドに入っています。株数と公開価格はまだ決まっていません。

## 背景

Anthropic は2021年に OpenAI の元メンバーらが立ち上げた会社で、AI の安全性を重視する「パブリック・ベネフィット・コーポレーション（公益目的会社）」として登記されています。The Verge によると、今年6月に非公開で申請しており、その後リークされた S-1 の内容が報じられていました。今回の公開で、会社自身の言葉による数字とリスクが初めて正式に出たことになります。

## 何が起きたか

- **売上**: 2026年上半期は **163億ドル**。前年同期の12億ドルから約14倍です（TechCrunch、Crunchbase News）。
- **損益**: 営業損失は6億9300万ドルで、前年同期の21億ドルから縮小しました。純損失は **807億ドル**ですが、Crunchbase News によると約9割は転換社債などの公正価値の変動による会計上の費用で、現金の流出ではありません。会社は「将来、黒字化を達成または維持できない可能性がある」と書いています。
- **顧客**: 9月末時点で、年10万ドル以上使う顧客が11,900社超、100万ドル以上が1,900社、1000万ドル以上が約250社です（TechCrunch）。
- **支配の仕組み**: 上場直前に、共同創業者7人（Dario Amodei、Daniela Amodei、Tom Brown、Jack Clark、Jared Kaplan、Sam McCandlish、Christopher Olah の各氏）が作る「Founder LLC」に **Class F 株を1株だけ発行**し、この1株に議決権全体の **50.1%** を持たせます。経済的な権利はありません。さらに2023年に作った長期利益信託（LTBT）が Class T 株を通じて取締役の過半数を選びます。社員向けには、限られた議題にだけ投票できる Class E 株も用意されます（S-1）。
- **計算資源の契約**: Supercomputing News の整理では、解約できない計算資源の購入契約の最低支払額は6月末時点で約 **2656億ドル** に増えました。S-1 には Broadcom との5年間のリース約1612億ドル（利息除く）、Google との最低支出約1145億ドル、Amazon との最低支出1100億ドルなどが並びます。Google と Amazon の分は「実際の使用量にかかわらず」支払いが必要です。
- **リスク**: リスク要因の記述は93ページに及び、将来のモデルが化学・生物兵器などの開発を助けうるという内容まで含まれています（Crunchbase News）。

## なぜ重要か

（編集部の視点）Claude の API や Claude Code を使っているチームにとって、今日すぐ何かが変わるわけではありません。S-1 には製品、料金、API の変更についての記述は見当たらないと報じられています。ただ上場すれば、Anthropic は四半期ごとに数字を公表することになります。**主要な AI ベンダーの経営状態を、公開情報で確かめられる**ようになるのは、ベンダー選定の材料として大きな変化です。

一方で、数千億ドル規模の計算資源の固定費を抱えていることもはっきりしました。売上の伸びが鈍れば、料金体系や無料枠の見直しにつながる可能性もあります（編集部の視点）。特定のモデルに強く依存した機能を作っているなら、別のモデルへ切り替えられる設計にしておく価値は上がっています。

## 反応・論点

- TechCrunch は、議決権が創業者の持ち株比率と見合わないため、「人類に壊滅的または存亡に関わるリスク」をもたらしうると自ら認める技術を作る会社に、一般株主がほとんど影響を及ぼせない点が議論を呼んでいると伝えています。
- CNBC は、この仕組みによって創業者が「当面のあいだ、株主投票にかけられるすべての事項の結果を決められる」という S-1 の記述を紹介しています。
- Crunchbase News は、7人の創業者がそれぞれ23万〜24.6万株とほぼ同じ数の Class A 株を持っている点を、CEO が突出して多く持つ一般的なスタートアップと比べて珍しいと指摘しています。また、史上最大の IPO になる可能性があるとしています。
