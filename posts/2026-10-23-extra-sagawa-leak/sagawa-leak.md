佐川急便は10月23日、Web サイトの「お荷物問い合わせサービス」が受けた不正アクセスについて第5報を出し、**最大約5323万件（重複を含む）**の個人情報が外部に流出した可能性があると発表しました。対象は、6月21日から9月30日までの約100日間に預かった荷物の、送り主と届け先の氏名・住所・電話番号などです。同じ日に、止めていた荷物追跡サービスも再開しました。NHK や日本経済新聞が16時台（日本時間）に一斉に報じ、X でも急に話題になっています。

## 背景

不正アクセスが見つかったのは**9月30日午前7時30分**です。佐川急便は同日に第1報を出し、10月1日の第2報で個人情報が流出した可能性を公表しました。あわせて荷物追跡や Web での集荷受付など一部のサービスを止め、同日正午にはインターネット貨物システムへの外部からのアクセスを遮断しています。個人情報保護委員会へは10月1日に速報を出しました。

その後、通販などの出荷元も自社の顧客への案内を始めています。たとえばユニ・チャームの直販サイトは10月15日、佐川経由で発送した一部の顧客のお届け先情報（氏名、住所、電話番号、送り状番号）が対象に含まれる可能性が高いと発表しました。

## 何が起きたか

第5報で分かったことは次のとおりです。

- **件数**: 流出した可能性のある個人情報は、現時点で最大約5323万件です。重複をある程度整理したうえでの数字ですが、送り状データには「相当数の重複」が残っていて、**実人数ではありません**。また、実際に外部へ流出したと確認した件数でもありません。
- **対象の情報**:
  1. 送り状データ（2026年6月21日〜9月30日、約100日分）の、ご依頼主とお届け先の氏名、住所、電話番号
  2. 運賃契約を結んでいる顧客の氏名、住所、電話番号
  3. Web サービス「スマートクラブ」会員の氏名、住所、電話番号、メールアドレス、会員ID
- **含まれないもの**: クレジットカード情報とパスワードは含まれていません。手書きの送り状で預けた荷物の情報も対象外です。区分ごとの件数は、重複が多く実人数を示せないとして公表していません。
- **二次被害**: 現時点で、不正利用などの二次被害は確認されていません。
- **サービスの状況**: 「インターネット貨物のお荷物問い合わせ」は10月23日に再開しました。一方、法人向けの「お荷物問い合わせAPI」、「飛脚宅配便受付」「飛脚往復便受付」「飛脚往復便（ゴルフ）受付」、「商品回収返金サービス」、2種類の「受取先変更」、「回収くん」は引き続き停止中です。
- **今後**: 対象の顧客には順次案内し、個別に案内できない人には今回の公表で通知に代えるとしています。個人情報保護委員会への確報は、佐川と出荷元の企業との連名で出す方向です。原因や侵入経路はまだ公表されておらず、外部の専門機関と調査を続けています。

## なぜ重要か

（編集部の視点）まず利用者として、**この夏に佐川で荷物を受け取った人の多くが対象になり得る**という点が大きいです。氏名・住所・電話番号がそろうと、「佐川急便です、お荷物の住所に不備があります」といった SMS やメールが本物らしく見えてしまいます。佐川も、同社を装った不審なメール、SMS、電話に注意し、記載された URL を開いたり個人情報を入力したりしないよう呼びかけています。

開発者、とくに EC やサービスを作るチームにとっては、**配送委託先の事故が自社の顧客情報の問題になる**ことがはっきりした事例です。ユニ・チャームのように出荷元が自分で調査・告知を行い、個人情報保護委員会への報告にも出荷元が関わります。自社サイトの「配送状況を見る」リンクや発送通知メールの文面が、偽 SMS と見分けやすいか、問い合わせ窓口の案内がすぐ出せるかを、この機会に見直しておくと安心です。

また、法人向けの追跡 API がまだ止まっているため、佐川の追跡情報をアプリやマイページに組み込んでいるサービスでは表示や連携が止まっている可能性があります。再開時期は決まり次第、佐川の公式サイトで案内されます。

## 反応・論点

- 佐川急便は「お客さまや関係者に多大なるご迷惑とご心配をおかけし、改めて深くおわび申し上げる」とコメントし、アクセス管理や監視体制の強化など、情報セキュリティ対策を見直しているとしています（日本経済新聞）。
- X では、「佐川」と「流出」「不正アクセス」などを含む投稿が、報道直後の16時台・17時台（日本時間）にそれぞれ約8000件ずつ出ました。前日まではほぼ1時間に数件でした（X API の投稿数集計より）。
- 問い合わせ先として、専用チャットと専用コールセンター（0120-28-3449、9時〜17時、土日祝も受付）が用意されています。
